# K-LEAGUE MANAGER

K리그 구단의 감독이 되어 선수단·전술·경기를 지휘하는 싱글 플레이 웹 축구 경영 게임입니다.

> ⚠ **현재 버전은 테스트 데이터로 동작합니다.** 구단명·연고지·홈구장은 공개된 일반 정보 기반의 개발용 값이고, 선수는 무작위로 생성한 **가상 인물**입니다. 능력치는 모두 **게임용 추정치**이며, 선수 사진·구단 엠블럼은 포함하지 않습니다(기본 실루엣·자체 배지 사용).

## 실행 방법 (처음 하는 분용)

1. **Node.js 설치**: https://nodejs.org 에서 LTS 버전을 설치합니다. (20 이상)
2. **터미널 열기**: Windows는 시작 메뉴에서 "터미널" 또는 "PowerShell", Mac은 Spotlight(⌘+Space)에서 "터미널".
3. **이 폴더로 이동**: `cd 경로/k-league-manager`
4. **패키지 설치** (처음 한 번만):
   ```bash
   npm install
   ```
5. **게임 실행**:
   ```bash
   npm run dev
   ```
   `Local: http://localhost:5173/` 이 보이면 브라우저에서 그 주소를 엽니다.
6. 끄려면 터미널에서 `Ctrl + C`.

문제가 생기면: `node -v`로 Node.js가 설치되었는지 확인하고, `npm install`을 다시 실행해 보세요.

## 현재 구현된 기능 (PHASE 0~1 MVP)

- 타이틀 / 새 게임(감독 이름·구단 선택) / 이어하기 / 세이브 불러오기·삭제
- 대시보드: 게임 날짜, 날짜 진행(일시정지·하루·보통·빠르게·매우 빠르게), 다음 경기, 순위 요약, 최근 경기, 부상·징계, 알림
- 선수단: 포지션 필터, 정렬, 모바일 카드형 목록, 다른 구단 선수단 보기
- 선수 프로필 카드(네이비·골드), 능력치, 포지션별 OVR, 시즌·통산 기록(게임 기록과 실제 기록 분리)
- 일정(목록·월간 달력), 순위표(승점·골득실·다득점·최근 5경기), 득점·도움 순위
- 전술·라인업: 6개 포메이션, 선발·벤치 배치, 포지션 적합도, 자동 선발, 전술 프리셋과 세부 지시
- 라이브 경기: 분 단위 중계, 하프타임, 교체(횟수·교체 기회 규칙), 경기 중 전술·포메이션 변경, 부상·퇴장 시 자동 일시정지, 경기 통계, 선수 평점·MOM
- 경기 결과 자동 반영(선수·구단·순위·감독 기록, 경고 누적·퇴장 징계, 부상)
- IndexedDB 저장(트랜잭션), 자동 저장, 세이브 버전·마이그레이션, 경기 중 새로고침 시 이어하기

## 폴더 구조

```
src/
├─ app/            레이아웃, 게임 시계
├─ components/     공통 UI (배지, 사진/실루엣, 토스트 등)
├─ data/           테스트 데이터 (구단 JSON, 가상 선수 생성기, 대회 규칙 설정)
├─ engine/         UI와 분리된 순수 게임 로직 (+ 단위 테스트)
│  ├─ calendar/    일정 생성
│  ├─ league/      순위 계산
│  ├─ match/       경기 엔진, 라인업
│  ├─ ratings/     OVR·포지션 적합도
│  ├─ tactics/     포메이션·전술 프리셋
│  └─ world.ts     새 게임, 하루 진행, 경기 결과 반영
├─ features/       화면별 컴포넌트
├─ repositories/   IndexedDB 세이브 저장소, 마이그레이션
├─ store/          Zustand 전역 상태
├─ types/          타입 정의
└─ utils/          날짜·난수 유틸
docs/              기획서와 개발 지침
```

## 실제 데이터 적용 원칙

실제 선수 데이터·사진·엠블럼은 출처와 이용 조건(재배포 가능 여부)을 확인한 뒤에만 넣습니다. 무단 크롤링·핫링크는 하지 않으며, 사용자가 적법하게 확보한 데이터를 가져오는 CSV/JSON 임포트 기능을 다음 단계에서 추가할 예정입니다. 자세한 내용은 `docs/K-LEAGUE-MANAGER-DESIGN.md` 3장을 참고하세요.
