# 개발 로드맵

| 단계 | 내용 | 상태 |
|---|---|---|
| PHASE 0 | 백업·복구, 구버전 세이브 보호, 가상 세계관(12개 구단) 적용, 3모드·픽셀 캐릭터·세이브 구조 설계 | 진행 중 |
| PHASE 1 | 모드 선택 화면, `SaveGame.mode`·`modeState`(스키마 v6), 모드별 메뉴·권한(`MODE_CAPABILITIES`), 감독 모드(현재 게임 기반) 분리, 픽셀 캐릭터 렌더러 시제품, 짧은 시즌(22라운드) 옵션 | 예정 |
| PHASE 2 | 구단운영 모드: 시설·유소년·팬·재정 등급, AI 감독 라인업 | 예정 |
| PHASE 3 | 선수 모드: 선수 생성·외형 선택, 개인 훈련, 주전 경쟁, 개인 평점, 계약·이적, 은퇴 카드 | 예정 |
| PHASE 4 | AI 간 이적, 임대, 2부·승강제 검토, 밸런스 | 예정 |
| 이후 | 모바일 앱 포장(웹 코드 재사용), 저장소 계층 교체 검토 | 범위 밖 |

범위 밖(현재): 온라인 멀티, 로그인, 클라우드 저장, 결제·광고, 3D, 경기 엔진 전면 재작성.
